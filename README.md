# HL_CCTV 營建站路污智慧判視系統

工地車輛出入口與外圍道路之路面髒污即時監測與離線錄影分析平台。

## 🌟 核心特色
1. **多重路污判別演算法**：
   - YOLO 車輛/人員遮擋過濾
   - CLAHE 局部對比強化（抗強光直射與陰影）
   - 分時段 HSV 雙通道直方圖比對
   - Canny 邊緣密度驗證（抗積水反光與平滑陰影）
2. **.ts 錄影檔全自動監控與抽幀**：
   - 遞迴監控 `D:\錄影\Record\` 下各鏡頭（`10.0.0.10`、`10.0.0.11`）產出的 30 分鐘 `.ts` 影片
   - 檔案穩定度安全檢查（自動略過 `.temp` 檔案）
   - 背景佇列自動批次抽幀分析並記錄違規精確秒數
3. **Web 儀表板與視覺化標註**：
   - 即時 MJPEG 影像串流
   - 瀏覽器端直接滑鼠拖拉標註 ROI 區域
   - 一鍵儲存乾淨/髒污基準樣本教學
   - 違規快照簿與對應秒數調閱

## 🚀 快速啟動
直接雙擊執行根目錄下的：
```bash
start.bat
```
啟動後瀏覽器自動開啟：`http://localhost:8088`

## ⚙️ 環境需求
- Windows 10/11
- Python 3.10+
- 相依套件見 `requirements.txt`
