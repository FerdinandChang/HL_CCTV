# 花蓮營建路污辨識系統 (HL_CCTV)

依據花蓮縣環境保護局《營建工程污染科技執法計畫》規格實作之工地出入口與外圍道路即時監測、貨廂防塵設施判視與離線錄影分析平台。

## 🌟 核心特色
1. **車斗防塵設施判視模組 (C-2 經費表)**：
   - 智慧定位貨廂頂部開口 65% 高度，車頭朝向自適應分析。
   - 工程綠色防塵網光譜與拉普拉斯紋理方差判定，精準區分已覆蓋／未覆蓋。
2. **路面色差與泥濘面積分析模組 (C-3 經費表)**：
   - YOLO 車輛／施工人員通行遮擋排除。
   - CLAHE 局部對比強化（抗強光直射與平坦陰影）。
   - 分時段 HSV 雙通道直方圖比對與 CIE LAB 色差輪廓提取。
   - Canny 邊緣密度驗證（抗積水反光與路面陰影）。
3. **.ts 錄影檔全自動監控與批次抽幀**：
   - 遞迴監控 `D:\錄影\Record\` 下各鏡頭產出的 30 分鐘 `.ts` 影片。
   - 背景佇列自動抽幀，路污與車斗違規次數獨立分離統計與秒數回放。
4. **GPS 定位與 GIS 座標合規**：
   - 紀錄精確經緯度並支援 Google Maps 外部定位連結。
5. **白天 (Light Mode) / 夜間 (Dark Mode) 雙向模式 Web 儀表板**：
   - 全自適應高對比度排版，支援瀏覽器端拖拉 ROI 與樣本教學。

## 🚀 現場啟動與部署方式
1. **建立桌面捷徑**：雙擊 `建立桌面捷徑.vbs`，即可在桌面生成專屬圖示捷徑。
2. **快速啟動**：
   - 雙擊桌面捷徑或 `啟動監測系統(無黑窗).vbs`：背景靜默運作並自動以全螢幕 App 模式開啟儀表板。
   - 雙擊 `啟動監測系統.bat`：帶有狀態檢查與日誌輸出之啟動模式。
3. **停止服務**：雙擊 `停止監測系統.bat` 一鍵完全釋放系統資源與 Port 8088。
4. **一鍵打包發行版**：執行 `python package_release.py`，即時輸出 5.78 MB 純淨便攜包 `HL_CCTV_Release.zip`。
